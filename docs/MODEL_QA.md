## 独立审计发现

核心时间注意力、向量门、softplus/残差、关系 beta、分组 softmax、接收负载与路径强度均可在正文找到公式对应。HGNN 具体结构、chi、偏置、均值损失、损失数值修复及离线单信号 LLM 特征属于工程选择，在 `METHOD_MAPPING.md` 逐项记录。

初次代码审计发现 temporal InfoNCE 展平会把其他预测时刻同一实体作为负例，以及 `no_align/no_path` 直接传给模型会触发模式枚举错误。**已确认修复**：训练器 `temporal_loss` 按时刻调用损失，`alignment_loss` 通用三维接口也按时刻均值；两项损失消融路由 `full` 模型后关闭对应 lambda。独立测试验证 batch 与逐时刻结果相等，重复时间不增加假负例。默认 node/edge mask 改为 labels>=0，独立扰动未知槽不改变结果且对应梯度为零。

混合未知/已知边路径候选也已修复：未知边强度设为零，预测与真值均在已知标签子图评价。单独回归测试验证更高强度未知边不会挤掉真实已标注路径。此修复不解决现实部分标注的覆盖选择偏差。
