# 研究缺口与论文表述边界

本工程完成的是可运行 DM-ROR 原型与公开来源审计后可重建的实验流程。要把结果作为论文真实供应链实验提交，仍需处理以下证据缺口。这里列出的差异不能用调参、抄写原稿表格或合成相同百分比代替。

## 原始实验和数据未追回

49 服务器已检查的论文项目及科研目录中，未发现能核验论文 SC-Auto、SC-Semi、SC-Energy 的完整原始数据、实际风险标签和作者实验日志；旧 DM-ROR 代码亦未在已检查范围发现。这是有限范围的查找结论，不是对整台服务器所有路径的存在性证明。

三个 SIM 数据集是独立合成数据；ICKG 是真实文本与机器抽取图，监督目标为未来报道代理。两类结果不能直接替代原稿数值。原稿声称的 AUC +5.7%、范围 +14.1%、Path-F1 +15.1% 等增益尚无对应原始运行证据，本工程没有验证这些断言。

下一步需要作者提供原始数据来源、构建版本、人工/弱标签规范、真实韧性来源、时间切分以及每个表格的日志和模型配置。若不能取得，应把论文重写为“模拟机制实验＋真实公开报道弱标签验证”，调整题目、摘要、结果和数据可用性声明的证据范围。

## 真实标签与因果传播

未来 risk-related 报道不等于真实业务中断；未报道不等于无风险。现有 ICKG 图缺少完成人工审核，可能有实体或关系错误，high_precision 只是筛选规则名。缺少真实韧性数据时不能从图度数生成并称其为库存冗余/替代能力。

真实数据没有 who-affected-whom 标签。即使模型可以从某源节点检索路径，也不能称候选路径被真实传播标签验证。要完成论文三任务，需独立收集有时间标记的中断事件、源节点、后续受影响实体、对应供应关系证据与路径贡献；并预先定义缺失/负标签、事件边界和人工标注一致性。

节点模型当前不以 source/event 为条件，threshold scope 是全图高风险集合。若论文坚持“给定源事件的影响范围预测”，应新增 incident-conditioned query 表示或独立干预/事件评价任务，并评估多事件重叠及相同图在不同源条件下输出变化。当前全图范围指标不能证明源特异影响预测。

## 方法规格未完全确定

- 稿件只写 HGNN；当前选择 R-GCN 风格编码器。需要注明该选择，或取得作者真实编码器配置。
- 稿件完整实体与邻域提示尚未作为当前缓存特征执行；冻结单信号 LLM 特征不等于完整 prompt 编码，也不等于端到端 LLM 微调。
- 文本抽取为规则/模拟来源；可选本地 LLM JSON 抽取工具有逐字证据校验，仍属于未人工审阅抽取。工具存在与整套数据经工具执行是两件事。
- 冻结 LLM 的预训练时间和潜在语料覆盖未独立审计。输入日期过滤只约束显式检索证据，不能证明模型在历史预测日已可取得，或排除预训练知识中的后期信息；真实实验仍属于回顾式分析。
- 原始 path BCE 对无界 pi 数学上不合法；本工程做了 `1-exp(-pi)` 修复。论文必须明确该变更，并区分 intensity、mapped score 和 calibrated probability。
- 关系独立归一化使跨关系总发送量不守恒；阈值头的无约束线性权重不保证韧性单调性。若要提出守恒/因果/物理解释，需要额外约束和独立测试。
- 重分配一次计算与 beam 多跳检索不能替代真实多步级联仿真。若论点关注长期传播动态，需要显式时间更新及其训练目标。

## 评估定义差异

当前 scope 同时保留每时刻 Top-K 排名指标和验证阈值集合的 Jaccard。阈值 Jaccard 在真值和预测均为空时记 1，应同时披露空集合天数和 `jaccard_positive_days`，避免弱标签稀疏场景的空集合匹配被误读为准确受影响范围预测。`jaccard_at_k` 与 threshold Jaccard 不能混写。

当前 path truth 是正边图中所有简单正前缀，预测为每源 top-K beam 候选，路径相等按节点序列判断。原稿未明确完整路径/前缀、实体关系区分、不同长度、真实空路径日、源集合、Path@K 分母和未知边处理。本工程已固定 Path@K 为可评源的至少一条精确路径命中率，并限制预测到已知标签边子图；这些约定仍需在论文中写清，不能假设与原实验值采用相同定义。全部边未知的真实集跳过 path 指标；部分标注的标签覆盖选择偏差仍需另外分析。

SIM 图和容量固定，五个模型 seed 是训练变动。84 个快照之间标签窗口重叠、训练/测试同属同一图，因此结果不能外推到独立企业或真实行业总体。建议补充多图种子、不同生成机制、扰动参数、无模板语言/真实文本对照、跨行业迁移和时间 block 置信区间；不能选择仅有利于完整模型的仿真规则或只报道正向消融。

## 基线和图表缺口

原稿共有 22 个基线：5 文本、7 图、6 传播、4 融合。实际执行的基线需在结果报告逐个列明。本工程小规模消融与冻结特征分类对照不能替代 BERT/RoBERTa/FinBERT/HGT/TGAT/TGN 等独立实现。缺少其模型、超参数和共同预算时，不声称 SOTA 对比完成。

论文 context-quality、robustness、sensitivity 与 case-study 图需要真实实验数据支撑。若本工程没有执行相应分组/扫描，只能记录为待开展；不能从模板画出曲线并配论文断言。训练 loss/validation 曲线与实际预测案例可以作为当前运行证据，不能被改名为未开展的研究分析。

## 交接后优先事项

1. 由作者确认原稿版本、HGNN 选择、完整提示输入和三个真实数据集是否存在。
2. 审核少量实体链接、风险报道规则、时间字段与缺失观测，估计弱标签的人工精度和覆盖偏差。
3. 采集可用的 operational resilience 及事件传播证据，再定义源条件任务和真实 path truth。
4. 在同一数据、同一切分和预算下增加原稿真实基线，报告全部运行与失败，不按测试成绩筛选数据/参数。
5. 根据真实运行重写论文结果和图注。交付结果的 config、数据哈希、checkpoint 和 predictions 作为回溯依据；原稿既有表中的数值不进入本工程实验统计。
