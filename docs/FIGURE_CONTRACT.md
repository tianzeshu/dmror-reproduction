# 补充实验图契约

核心结论：补充图展示保存的测试预测在预先定义的历史文本和图结构分层中的表现，以及一个固定规则选择的模拟案例；不预设完整模型优于消融模型，也不据此认定现实因果传播。

采用当前工程的 Python / matplotlib 工作流。输出白底、Arial 7 pt（缺失时使用 DejaVu Sans）、克制蓝色/橙色编码；宽度 183 mm。每张图保存 PNG（300 dpi）、可编辑文字 SVG 和 TrueType PDF。绘图不改动训练器、模型、数据或检查点。

## 分层表现：quantitative grid

`scripts/plot_supplement.py` 只读取 `data/prepared` 的数组和 `results/formal` 的实际完成运行。比较 `full` 与 `no_stm`，使用固定模型种子 17、29、43、71、101；不使用测试结果选择种子、分层或分类阈值。

三个面板分别提供独立证据：

1. 最新有效历史文本的年龄：`(0,7]`、`(7,14]`、`(14,30]` 天、`>30` 天和无历史文本。年龄取各节点—快照有效槽中的最小 `delta`。模拟集最新文本本来只在 1–7 天，因此其他年龄层可能没有样本，必须显示 NA。
2. 同一最新文本的置信度代理：0.55、0.80、0.90、其他值和无历史文本。多个槽年龄相同时选最小槽索引；置信度不是人工校准的文本质量概率，不能解释为受控文本质量实验。0.80 也可能来自模拟旧文本，最终统计以实际选中槽位为准。
3. 观测静态有向图的入度：0、1–2、3–5、6 及以上。入度统计有向边数组，保留并行关系的计数。

每层展示同一测试节点—快照上的 `AUPRC(full) - AUPRC(no_stm)`；AUPRC 定义为 sklearn `average_precision_score`。至少需要 20 个已知标签样本、2 个正例与 2 个负例，否则该层标为 NA。图内保留支持样本数和正例数；同一节点在多个快照中出现仍为不同预测任务，不能当作独立企业样本。

只有五个预定义种子均存在、每个配对均完整且该层均有效时，才汇总五个配对差值的均值与样本标准差（ddof=1）；每个配对点同时显示。未完整时只展示实际有效点并明确不提供五种子汇总；不补齐缺失值，也不把单种子 SD 写成零。种子波动不是置信区间。重叠预测窗口和重复节点造成相关性。本图为事后描述性分层，不提供 p 值、因果推断或受控鲁棒性结论。

## 模拟案例：schematic-led composite

仅对 `SIM-Semi` 的 `full`、seed 17 绘制案例。快照固定为按索引排序的第一个同时具有观测起点和正模拟传播边的测试快照；起点固定为该快照最小索引的观测起点。不得根据预测好坏改选案例。如果不存在满足规则的快照，记录跳过原因。

观测图取该起点有向可达的两跳子图；默认 beam width=10、top K=5、max hops=2，与图中显示的范围一致。beam path 得分使用保存的非负 `test_edge_score` 连乘（按 log 求和），不重新归一化，也不将传播强度当作概率。零分边不能产生候选路径；不允许重复节点。相同分数以节点序列、边序列固定排序。

三个面板为：模拟失败真值；保存的节点预测概率及验证集选出的分类阈值；候选路径、模拟成功传递边和模型传播强度。所有两跳节点和观测边保留，预测命中与漏报均显示，不删除失败例。坐标仅为确定性布局，不能表示实际地理位置或经济距离。橙色模拟失败环及蓝色预测标记提供颜色之外的区分。

案例只能说明模型输出与独立模拟器之间的对应关系。模拟成功传递边不证明现实组织因果关系；多个传入负载可能共同耗尽库存。`ICKG-Weak` 没有真实传播边标签和观测起点，本脚本跳过其因果案例，不补造路径真值。

## 追溯、源数据与 QA

读入每个结果时验证完成状态、结果声明的数据 SHA-256、配对种子、严格相同的测试索引和标签、预测维度与概率合法性。测试索引必须与当前数据 `split == 2` 完全一致。数据变化后旧预测不能继续生成图。

输出 `source_data/strata_rows.csv` 保存实际绘图对应的逐节点—快照预测及分层值；`strata_metrics.csv` 保存各个种子的 AUPRC、配对差值、支持数与 NA 原因；`strata_summary.csv` 保存种子集合及汇总。案例输出全部显示节点、边、坐标、真值、概率、阈值、强度、候选路径序列和包含关系。`input_manifest.json` 保存输入文件的 SHA-256、测试 query/target 截止值、划分边界、运行身份及跳过原因；清单仅使用工程相对路径。`captions.md` 保存每张图的定义与限制。

最终运行者应检查 PNG 的文字、图例、概率色标、NA 标记和漏报是否清楚；打开 SVG/PDF 检查文字可选；复核输出源数据和输入哈希。此脚本不在缺失实际预测时生成示例图或论文数值。

运行：`python scripts/plot_supplement.py --results results/formal --data-root data/prepared --output reports/supplement`。
