## 计数定义

- 企业、产品、材料、行业、地域统计不同实体 ID 的数量，总节点为五类之和。
- 关系统计不同 `(source, target, relation_type)` 三元组；要求合法类型、合法端点、无自环和无重复。
- 文本统计原创合成文档记录，每条有唯一 ID、日期、实体链接和正文。它们不是抓取的真实新闻或真实公司公告。
- 风险信号统计结构化信号记录，每条关联对应文本及实体。全部信号的数量与单个预测时点检索到的 Top-K 信号数不同。
- `#Risk Labels` 在本构建中定义为带已知二元标签的 `(query_time, entity)` 实例总数，包含 0 和 1。它不是正类数量，也不是将所有其他实体认定为负类。未标注实例在训练张量中为 `-1`。
- 边传播真值由仿真器生成，单独统计，不并入表 1 的节点风险标签数。

上述定义是本次构建的明确约定。原稿未提供原始记录和完整标注规则，不能仅从数量判断与原稿标注口径严格等价。

## 生成与验收

生成规则与固定随机种子保存在 `dmror/build_table_scale.py` 和每个数据集的 `metadata.json`。构建过程中保留原来的小型 SIM 数据和 ICKG-Weak，历史结果继续对应其原有数据 SHA-256。

```bash
python scripts/verify_table_scale.py --data-root data/table_scale --output reports/table_scale/data_validation.json
# 从头重建到尚不存在的新目录
python -m dmror.build_table_scale --all --output data/rebuilt/table_scale
```

重建数据可将验收命令的 `--data-root` 改为 `data/rebuilt/table_scale`。生成器拒绝替换已有 `dataset.npz`。验收程序读取实际记录和 `dataset.npz`，核对数量、唯一性、实体引用、时间范围、已知/未知标签、文本检索的历史边界及训练/验证/测试划分。元数据中的数字不能替代文件校验。

## 实验解释

新规模实验使用独立结果目录和新的数据摘要。报告必须给出实际执行的模式、种子、训练预算、特征编码器和指标。旧 SIM 结果不移作新规模的结果；模型分数来自实际训练评估，不根据原论文 Table 2–5 的数字生成。

规模吻合只能证明构建数据符合该数量约束。合成拓扑、文本、韧性属性和仿真标签的结果用于工程验证与模拟研究，不能作为原论文真实供应链实验结论的证据。哈希特征实验亦不能称为完整 LLM 编码实验。
